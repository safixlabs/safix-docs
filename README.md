# Safix docs

Documentation site for [Safix](https://github.com/safixlabs/safix), the private credit network for tokenized stocks and real-world assets.

Built with Next.js and Tailwind CSS v4, statically exported. Editorial design language: parchment canvas, serif headings at regular weight, DM Sans body, a single blue accent.

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

The static site is written to `out/`.
